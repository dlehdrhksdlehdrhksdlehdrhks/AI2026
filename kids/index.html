1. 프로젝트 개요 & 아키텍처

Zero-Dependency & 경량화

React, Vue 등 무거운 프레임워크와 Node/NPM 빌드 과정 없이, 오직 브라우저 표준 기술(ES6+)로 100% 실행 가능한 극도로 경량화된 단일 파일 구조를 채택했습니다.

초고속 1.4만건 연산 엔진

Virtual DOM 오버헤드가 없으므로 filter() 등 순수 JS 메모리 연산과 네이티브 렌더링을 통해 1초 이내에 방대한 데이터의 검색/필터링을 완료합니다.

완벽한 폐쇄망 호환성

공공기관 내부망, 보안 통제 구역 등 복잡한 서버/빌드 환경 구축이 불가능한 로컬 환경에서도 단일 index.html 파일 하나로 즉시 실행됩니다.

2. 타겟 사용자 페르소나 및 시나리오

지자체 & 경찰서 담당자

안전 예산 집행 우선순위 수립

  • 관할 구역 내 F등급(고위험) 사각지대를 즉각적으로 모니터링 및 원클릭 필터링.
  • 정책 보고서 브리핑 문장 자동 생성 기능을 활용해 공문 첨부용 초안을 즉시 확보.
학부모 & 교육자

실제 통학로 안전성 직관적 확인

  • 자녀가 다니는 초등학교/어린이집을 검색하여 배정된 CCTV 설치 대수를 직접 확인.
  • 해당 구역의 안전 취약 지수(0~100점) 및 5단계 등급을 통해 인프라 취약성을 체감.
공공데이터 분석가

공간 데이터 분석 및 추출

  • 무거운 지도 API 없이 2D 위경도 산점도(Scatter)를 통해 지역별 밀집 편차를 시각적 분석.
  • 조건부 필터링된 결과 데이터를 UTF-8 BOM CSV 형식으로 내보내어 엑셀 연동.
