종합 성찰

1~7번 프로젝트를 지나며 가장 뿌듯했던 순간과 가장 힘들었던 순간을 남겨둔다.

🎯

잘됐던 점 — 나의 진로 리포트

8개 프로젝트 중 가장 결과물이 잘 나온 건 04번, 부산대 컴퓨터공학부의 인공지능전공과 컴퓨터공학전공을 비교한 진로 리포트였다.

단순히 학과 소개를 나열하는 데 그치지 않고, 대학알리미 등 공시 데이터를 직접 찾아 경쟁률, 학비, 1인당 교육비 같은 실제 수치까지 비교에 반영하다 보니 막연했던 전공 선택 고민이 실제로 정리되는 느낌을 받았다.

"내가 궁금했던 질문에 진짜 답을 찾은 프로젝트."
🛠️

어려웠던 점 — 부산 축제 가이드의 API 키

07번 부산 축제 가이드를 만들 때, Open API 키를 계속 못 읽어와서 한참을 헤맸다. 처음엔 내가 환경변수를 잘못 넣은 줄 알았다.

알고 보니 원인은 AI가 Vercel 배포 환경에 맞지 않는 방식으로 코드를 작성해준 것이었다. 프롬프트에 "Vercel 환경에 맞게 작성해줘"라고 다시 명확히 요청하니 그제서야 정상적으로 작동했다.

로컬에서는 되는데 배포하면 API 키를 못 읽어옴 → 환경변수 문제로 오해
원인은 Vercel 환경에 맞지 않게 작성된 코드였음
"Vercel 배포에 맞게 작성해줘"라고 다시 요청 → 정상 작동
배포 환경마다 코드 작성 방식이 다를 수 있다는 걸 몸으로 배운 순간.
